# FulvoLegends
Fulvo Legends- Godot
![image](https://github.com/user-attachments/assets/67718e3d-634a-407e-b20e-efd794c7be51)

FulvoLegens es un videojuego multiplataforma 2D desarrollado con el motor gráfico Godot 4, que te sumerge en la experiencia de jugar con los mejores futbolistas del mundo. Diseñado para ofrecer partidas rápidas y competitivas, este juego permite a los jugadores no solo elegir a sus estrellas favoritas, sino también desafiar a amigos para demostrar quién tiene las mejores habilidades en la cancha.
